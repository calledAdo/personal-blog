## Inline and display math

Inline math sits in the text with single dollar signs, like the famous
identity $e^{i\pi} + 1 = 0$ or the bound $\mathcal{O}(n \log n)$.

Display math uses double dollar signs and renders centered on its own line:

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

You can write aligned multi-line derivations too:

$$
\begin{aligned}
\nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0} \\
\nabla \cdot \mathbf{B} &= 0 \\
\nabla \times \mathbf{E} &= -\frac{\partial \mathbf{B}}{\partial t} \\
\nabla \times \mathbf{B} &= \mu_0\mathbf{J} + \mu_0\varepsilon_0\frac{\partial \mathbf{E}}{\partial t}
\end{aligned}
$$

## Formatting

You get **bold**, *italic*, `inline code`, [links](https://astro.build), and
lists:

- First point
- Second point, with math $\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$
- Third point

> Block quotes work for highlighting a key result or a citation.

### Code blocks

```python
import numpy as np

def gaussian(x, mu=0.0, sigma=1.0):
    return np.exp(-((x - mu) ** 2) / (2 * sigma**2)) / (sigma * np.sqrt(2 * np.pi))
```

## Citations

Cite a source from `src/content/references.bib` with `[@key]`. For example,
information theory begins with Shannon's foundational paper [@shannon1948], and
the theory of computation with Turing [@turing1936]. The formatted reference
list is generated automatically below.
